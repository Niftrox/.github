# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities **privately** — do not open a public issue.

- **Preferred:** GitHub's private vulnerability reporting — *Report a vulnerability* on the affected repository's **Security** tab.
- **Email:** security@niftrox.com

We aim to acknowledge a report within **3 business days** and to keep you updated as we investigate.

## Scope

This policy covers repositories in the Niftrox organization. ChangeOps is a private, pre-launch B2B platform; production access is restricted to the Niftrox team.
